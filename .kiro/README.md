# Kiro project artifacts

The original Kiro IDE feature spec is in
[`specs/scenario-artifact-contracts/`](specs/scenario-artifact-contracts/).
Its requirements, design, tasks and native configuration are the Kiro
artifacts for this project. This index describes those files; it is not
itself evidence of Kiro execution.

Later tool improvements are documented under **Kiro usage** in the
[project README](../README.md#kiro-usage). No steering, hooks, Powers, Web,
CLI or Crew use is claimed here.
